# Inspection AI

Веб-приложение для автоматизированной инспекции фото- и видеоматериалов с помощью модели компьютерного зрения YOLO. Помогает анализировать материалы обследования, находить объекты целевого класса, сохранять визуальные доказательства обнаружений и формировать сводные отчёты.

## Описание проекта

Оператор загружает фотографии, видео или ZIP-архив с материалами, указывает зону, имя оператора и порог уверенности модели. Node.js ставит задачу в очередь и передаёт её отдельному Python-процессу с Ultralytics YOLO. Результаты распознавания — классы, уверенность, координаты рамок и индексы кадров — сохраняются в SQLite и отображаются в интерфейсе вместе с размеченными изображениями или видео.

Изображения из архива обрабатываются как один анализ и сводный отчёт. Для завершённых задач доступны статистика, журнал, кадры с детекциями, проверка/смена статуса обнаружений и экспорт в JSON или PDF. PDF содержит кадры, на которых модель обнаружила объекты.

Это вспомогательный инструмент: качество зависит от обученной модели и её параметров, поэтому результаты нужно проверять оператору. Интерактивная карта и демонстрационный маршрут дрона тестовые — без реальных геоданных и управления дроном.

## Возможности

- Загрузка фото и видео, до 20 файлов за раз, ZIP-архивы с вложенными папками.
- Последовательная фоновая обработка YOLO; кадры с рамками и размеченные видео.
- Анализ публичных ссылок Google Drive и видеопотоков RTSP/RTSPS/HTTP/HTTPS.
- Статистика, логи, сводные отчёты, статусы проверки обнаружений.
- Экспорт отчётов и всех кадров с детекциями в PDF, а также JSON.
- Интерактивная демонстрация маршрута дрона без GPS и реального управления.

## Архитектура

- `server.js` — Node.js HTTP-сервер и API, встроенный SQLite, загрузка и обработка архивов, очередь задач, отчёты и раздача файлов.
- `yolo_worker.py` — Python worker для инференса Ultralytics YOLO. Получает настройки через stdin и возвращает события в формате JSON Lines.
- `run_yolo.py` — отдельный CLI для локального анализа, сайтом не используется.
- `templates/index.html`, `static/app.js`, `static/style.css` — веб-интерфейс.
- `inspection_data/` — локальная SQLite-база, загрузки и результаты. Не публикуйте реальные данные из этой папки.

## Требования

- Node.js 22.13 или новее.
- Python 3.10+ и пакеты из `requirements.txt`.
- Файл модели YOLO, по умолчанию `C:\Users\sasak\Desktop\best.pt`.

## Запуск в Windows PowerShell

```powershell
npm.cmd install
py -3 -m pip install -r requirements.txt
npm.cmd start
```

Откройте `http://127.0.0.1:5000`. Для другой модели задайте путь перед запуском:

```powershell
$env:YOLO_MODEL_PATH = "D:\models\best.pt"
npm.cmd start
```

Для Python-команды, отличающейся от `py -3`, используйте `PYTHON_EXECUTABLE`. `INSPECTION_DATA_DIR` меняет каталог базы/файлов, а `PORT` — порт сервера.

## Доступ через интернет

Для временной публикации предусмотрен Cloudflare Tunnel: установите `cloudflared` и запустите `start-public.ps1`; для остановки используйте `stop-public.ps1`. Скрипт генерирует случайный пароль и включает Basic Auth для всего сайта и API. Нужны исходящие TCP/UDP-соединения на порт 7844; доступность туннеля зависит от сети. URL временный и действует только пока запущены Node.js и `cloudflared`. Не открывайте порт сервера напрямую в роутере.
